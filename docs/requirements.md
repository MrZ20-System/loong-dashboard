# LoongBoard V1 Requirements

This document is a concise repository-local view of the sole execution
baseline: `../LOONGBOARD_V1_TECHNICAL_DEVELOPMENT_PLAN.md`. It is not a second
product specification.

## Product scope

LoongBoard is a local-first, single-user engineering workspace. V1 provides:

- GitHub pull-request and issue activity lists;
- deterministic pull-request domain labels from changed file paths;
- local Git pull-request diff and full-file reading;
- a DSH-backed general Agent chat;
- a Markdown/Git knowledge repository;
- scheduled prompts sent to the Agent.

## Source of truth

Markdown files and Git are the Knowledge source data. SQLite stores indexes,
durable product state, and runtime state. Worktrees are disposable caches;
Agent Sessions are user state.

## V1 exclusions

V1 does not add GitHub write operations, PR/Issue summaries generated by AI,
AI-based domain classification, DSH Web UI integration, a DSH Plugin, a
product-level Agent permission system, PostgreSQL, Redis, queues, remote
control planes, or speculative provider abstractions.

## Boundary requirements

- HTTP request and response schemas are owned by `packages/contracts`.
- Only `packages/agent-runtime-dsh/**` may import `@deepseek-ai/*`.
- Only `packages/github/**` may execute `gh`.
- Local Git commands belong to `packages/git-workspace/**`; Knowledge may use
  a narrowly scoped Git checkpoint service.
- Raw SQL belongs only to `packages/database/**`.
- The health contract is `GET /api/health` returning HTTP 200 and JSON
  `{ "status": "ok" }`.
